# Memoforge для Zcode

Самостоятельный русский пакет 2.1.0. Общее ядро, отдельные данные и сценарии.

Сценарии: memo — новый меморандум; continue — продолжение и согласования; status — статус; style — профиль стиля; brief — краткая записка из готового меморандума.

Модель выбирается в Zcode, writer_model=inherit. По умолчанию memo_language=ru, ui_language=ru, dashboard=false. Юрисдикция задаётся вопросом, русский язык не ограничивает её Россией.

Данные: ~/.zcode/plugin-data/memoforge-zcode; в Windows — LOCALAPPDATA/zcode/plugin-data/memoforge-zcode. Задачи сохраняются отдельно от кэша плагина. Другую платформу нельзя использовать для продолжения уже начатой задачи.

Включены десять MCP-сервисов. Установка не обеспечивает их авторизацию; недоступные источники отражаются как пробелы исследования.

После установки: `scripts/mf deps install`, затем `scripts/mf deps check`. Подробный [протокол](router.md), [сценарии](skills/memo/SKILL.md). MIT, оригинальный автор Grigorii Moskalev.

## Установка из репозитория

Нужны Python 3.9+ и установленный хост. Из корня исходного репозитория:

```bash
python3 scripts/build_platforms.py --platform zcode --out dist
python3 scripts/install_platform.py zcode dist/marketplaces/zcode
```

В Windows используйте `python` вместо `python3`. Установщик регистрирует отдельный локальный
marketplace, устанавливает только этот плагин, проверяет версию и библиотеки. Остальные плагины
сохраняются. Папку `dist/marketplaces/zcode` сохраняйте для последующих обновлений.
После изменения исходников повторите сборку. Установщик ZCode сам обновляет кэш той же версии штатной командой plugins update.

На macOS установщик ZCode использует штатный встроенный CLI приложения через Node.js.
В остальных средах он ищет `zcode` в PATH. Для Codex используется `codex` из PATH.

## Первая задача

Откройте новую сессию хоста с нужной рабочей папкой. Выберите навык `memo` пакета
`memoforge-zcode` и напишите вопрос, например: «Подготовь внутреннюю записку на русском:
может ли учебный клуб публиковать фотографии участников?». Ответьте на уточнения и согласуйте
план. Навык `continue` возобновляет задачу, `status` показывает её положение и файлы.
Проверять другой хост через ту же задачу нельзя: создайте отдельную задачу.

`style` предлагает действия list/new/use/show/delete; `brief` создаёт краткую записку из
завершённого меморандума. Результаты открываются по абсолютным ссылкам из ответа хоста.

## Проверка

`python3 scripts/ci/check_platforms.py` в исходном репозитории распаковывает оба ZIP вне
репозитория и проверяет автономный цикл и русский DOCX с фикстурами. Это не проверка модели.
`python3 scripts/verify_platform_runtime.py zcode /absolute/test/folder` выполняет
реальный запуск до первого вопроса, сохраняет состояние и отчёт. Для завершённой проверки
через интерфейс Desktop используйте `--evidence-only`. Успех требует настоящих файлов аналитика
и текущего gate. Внешние MCP могут требовать отдельного входа; отсутствие доступа не является
проверенным результатом исследования.

На macOS в ZCode 3.14.4 реальная сессия проверяется через Desktop с выбранной моделью:
встроенный headless CLI может сообщать «Select a model before continuing». Это состояние хоста;
установщик и пакет работают независимо от него. Секреты и личные настройки не копируются.
