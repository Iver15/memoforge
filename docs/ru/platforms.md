# Memoforge для Codex и ZCode

[Установка Codex](../../platforms/codex/README.md) · [Установка ZCode](../../platforms/zcode/README.md).

| Свойство | Claude | Codex | ZCode |
|---|---|---|---|
| Пакет | memoforge | memoforge-codex | memoforge-zcode |
| Модель автора по умолчанию | opus | inherit | inherit |
| Язык новых задач | английский | русский | русский |
| Панель Artifact по умолчанию | включена | выключена | выключена |
| Резервный каталог данных | ~/.claude/plugin-data/memoforge | ~/.codex/plugin-data/memoforge-codex | ~/.zcode/plugin-data/memoforge-zcode |

Данные включают зависимости, кэш интерпретатора и профили стиля. Хост может передать свой
каталог данных; чужой каталог Claude новая сборка не использует. В Windows резервная цепочка
начинается с LOCALAPPDATA. Настройки разрешаются как флаг → переменная хоста → собственный
options.json → default. В Codex префикс `PLUGIN_OPTION_`, в ZCode `ZCODE_PLUGIN_OPTION_`.

Задача получает `runtime_platform`. Старые задачи без поля принадлежат Claude. Несовпадение
выдаёт `platform_mismatch`: продолжайте через исходный хост. Задачи сохраняются вне кэша плагина.
Переезд пакета и повторная установка не удаляют их. Модель выбирается средствами хоста;
`writer_model` новых платформ принимает только `inherit`.

## Проверка версии 2.1.0

В каждом хосте проверьте пять сценариев memo/continue/status/style/brief. Новый memo должен
иметь ru/ru, а результат аналитика — пройти штатный report перед показом текстового gate.
Ответ передаётся с текущими step/attempt/generation; устаревшее поколение отвергается.

Полный fixture-прогон проверяет переходы, схемы, публикацию и OOXML. Настоящий native-прогон
отдельно проверяет загрузку инструкций, работу подагента и продолжение после ответа.
Объявленные десять MCP-сервисов не означают успешный вход: доступность каждого источника
фиксируется отдельно. Пробелы исследования должны оставаться видимыми в записке.

Зависимости устанавливаются собственным launcher через `deps install`, а `deps check` новых
пакетов действительно импортирует модули. Кэш содержит абсолютный путь к интерпретатору;
повторная установка зависимостей заменяет старые бинарные модули в собственном каталоге.
Основная проверка выполнена на macOS; Windows проверяется матрицей CI и не объявляется
проверенным локальным Desktop-сценарием.
