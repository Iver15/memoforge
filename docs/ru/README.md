Имена команд, полей JSON, фаз, кодов ошибок и файлов сохранены. Перевод не меняет программные контракты или применимое право. Согласование с пользователем в оригинале называется *gate*, фиксация источников — *freeze*, резервный сценарий — *fallback*, краткая справка для принятия решения — *decision brief*.

`docs/phases.md`, `modes.md`, `events.md`, `always-deliver.md` и `permissions.md` создаются из кода командой `mf docs render`. Их эталонные версии сохранены, чтобы `mf docs render --check` продолжал выявлять расхождения. Русские версии в этой папке — отдельные переводы; после изменения эталона их нужно сверять и обновлять. При расхождении перечней и значений приоритет имеют код и JSON-схемы.

[История изменений](../../CHANGELOG.md), [архив v1](../attic/) и исполняемые инструкции агентов/навыков сохранены на языке оригинала. Это отдельные материалы, не вошедшие в перевод актуального пользовательского и технического справочника. Лицензия MIT также сохранена в оригинале.
