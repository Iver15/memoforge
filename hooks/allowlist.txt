# memoforge — WebFetch/MCP-fetch auto-allow host list (ТЗ §8.1, §8.2)
#
# One host per line. Everything after `#` is a comment. A host matches when the URL host is
# equal to it or ends with `"." + host` (suffix match with a dot), so `europa.eu` covers
# `eur-lex.europa.eu` but never `evil-europa.eu`. Readers:
#   * `hooks/permission_gate.py --mode fetch` — the PreToolUse auto-allow decision;
#   * `hooks/build_hooks.py --inline-fallback` — the generated one-line fallback hook;
#   * `mf docs render permissions` — the README block for `~/.claude/settings.json` (§8.2).
#
# Scope: regulators, courts, legislatures, standards bodies and the two privacy NGOs whose
# trackers the research layers actually cite. Law-firm blogs and commentary publishers are
# deliberately absent — a user grants those in `~/.claude/settings.json`.
#
# 108 hosts active + 3 in the `optional` group (off by default) = 111: the v1 `hooks.json` list, the
# LegalViz reader of D-105 and the `legislature` group (plus the Austrian DPA) of D34-02, as
# corrected by the reachability sweep of D-145 and extended by the `legislature-api` group of D-148.
